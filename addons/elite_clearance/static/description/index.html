Clearance Files

One job file per clearance instruction — documents, disbursements, billing.

Built for a customs clearance and logistics services provider: the file is the object the whole business hangs on, and every cost and every revenue line posted against it carries its analytic account.

A gate on the documentation

Each service type carries a checklist template. Opening a file generates the checklist; work cannot start while a mandatory document is missing, unless an approver signs a written waiver that is posted to the file's audit trail. Receiving documents stamps one shared transaction timestamp for everything saved together, with a wizard for bulk back-dating.

Out-of-pocket disbursements that actually reconcile

Expenses run draft → submitted → approved → settled. A direct settlement debits the out-of-pocket account against cash, bank, mobile money or an aggregator journal. A cash advance instead sits on the employee's advance account until it is justified with supporting documents, which is what moves it onto the file.

Billing that clears the balance sheet

The client invoice recharges disbursements at cost against the out-of-pocket account — clearing it — and adds the fee lines: a commission computed from the service type's rate, plus the customs service fee keyed from the declaration. A file is complete only once that invoice is posted, and reopening a closed file needs a manager and a written reason.

Approvals you configure, not hard-code

Waiver, expense, disbursement and billing approvals each take an explicit list of users under Settings → Clearance. Where no list is set, the Clearance Manager and Clearance Finance groups apply.
