ODOO 19 TEST LAB — Elite Advisors clearance module
===================================================

Everything in this folder is already set up. You only do steps 1-3.

STEP 1 — Install Docker Desktop (one time, ~5 minutes)
   Download: https://www.docker.com/products/docker-desktop/
   Run the installer, accept the defaults (WSL 2), restart if asked.
   Then open Docker Desktop and wait for "Docker Desktop is running"
   (whale icon in the taskbar stops animating).

STEP 2 — Start Odoo (two commands)
   Open PowerShell (Start menu, type "powershell"), then:

       cd "$env:USERPROFILE\Desktop\odoo-lab"
       docker compose up -d

   The first run downloads ~2 GB (Odoo 19 + PostgreSQL). Wait for it
   to finish. Later runs start in seconds.

STEP 3 — Create the database and install the module
   1. Open your browser at:  http://localhost:8069
   2. You get a "Create Database" form. Fill in:
        Master Password : anything you like (write it down)
        Database Name   : clearance_dev
        Email / Password: your login for this test system
        Demo data       : TICK THIS BOX  (it loads the sample
                          service types and document types)
      Click "Create database" and wait — first time takes a minute.
   3. Log in. Go to Settings, scroll to the bottom,
      click "Activate the developer mode".
   4. Go to Apps. Click the "Update Apps List" menu item
      (top of the Apps screen in developer mode), confirm.
   5. In the Apps search box, REMOVE the "Apps" filter tag first,
      then type: Clearance
   6. Click "Activate" on "Clearance Files". Done.

You now have a "Clearance" menu. Try this:
   - Files -> Clearance Files -> New
   - Pick any client, service type "Import clearance — sea freight"
   - The document checklist fills itself. Save.
   - Press "Start Work" -> it refuses (documents missing). Good.
   - Waiver tab -> write a reason -> Request Waiver -> Approve Waiver
   - "Start Work" now succeeds.

USEFUL COMMANDS (PowerShell, inside this folder)
   docker compose up -d          start Odoo
   docker compose down           stop Odoo (data is kept)
   docker compose logs odoo      see the server log if something fails
   docker compose restart odoo   restart after changing module code

IF THE MODULE DOES NOT APPEAR IN APPS
   - Did you remove the "Apps" filter in the search box? (step 5)
   - Did you run "Update Apps List"? (step 4)
   - addons\elite_clearance\__manifest__.py must exist at exactly
     that depth (it does — this folder was set up automatically).

_module_backup.zip is a spare copy of the module. You can delete it.
